## ✨ Overview

**DSA Streak Tracker** is a personal DSA practice tracker designed to help build a consistent problem-solving habit.

The app combines:

- 🔥 Daily streak tracking
- 🗺️ Fixed DSA roadmap
- 📝 Daily practice logs
- 📊 Progress analytics
- 🧩 Topic-wise problem tracking
- ⏱️ Practice time tracking
- 🏆 Streak milestones
- 💾 Local data persistence

The application is **local-first**, meaning your tracker data is stored locally using `localStorage` and does not require a backend.

## ✨ Features

### 🔥 Streak Tracking

- Current streak
- Longest streak
- Today's practice status
- Streak warning when today's practice is pending
- Optional Streak Freeze
- Monthly freeze limit
- Milestone celebrations
- Local timezone-aware streak calculation
- Midnight rollover handling
